Обрабатывает растровые изображения **внутри** документов Word и презентаций
PowerPoint, не разбирая сам документ.

## Зачем это сделано

Документ с фотографиями весит сто мегабайт, потому что каждая картинка внутри —
снимок с телефона в исходном разрешении. Открывается медленно, по почте не
уходит, при печати ведёт себя непредсказуемо.

Обычный путь — вытащить картинки, обработать, вставить обратно. На этом пути
теряется всё: положение, обтекание, подписи, привязка к абзацу.

Программа работает с изображениями **на месте**: документ остаётся тем же
документом, меняется только то, что внутри картинок.

## Принципы

**Вёрстка не трогается.** Положение, размер на странице, обтекание, привязка —
всё остаётся как было. Меняются пиксели, а не разметка.

**Цветовой профиль выбирается явно.** Как и в остальных программах Audion: для
экрана одно, для печати другое, и решает это человек.

**Исходник не меняется.** Результат пишется отдельно.
