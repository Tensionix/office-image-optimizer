# Audion Office Image Optimizer

Portable-проект для обработки встроенных растровых изображений внутри Microsoft Office `DOCX` и `PPTX`.

Текущая структура проекта:

- `system_core\app\` содержит Python-код приложения;
- `runtime\` содержит embedded Python runtime;
- `config\` содержит defaults и ICC-профили;
- `GitHub\` содержит основную документацию проекта для репозитория и релизов.

Основные лаунчеры лежат прямо в корне проекта:

- `launcher_project.cmd` - английский лаунчер
- `launcher_project_picker.cmd` - английский лаунчер с picker
- `launcher_project_ru.cmd` - русский лаунчер
- `launcher_project_picker_ru.cmd` - русский лаунчер с picker
- `launcher_gui.cmd` - desktop GUI-shell поверх существующего CLI

Служебные лаунчеры остаются только на английском:

- `builder_main.cmd` - сборка и упаковка
- `launcher_tools.cmd` - сервисные, лицензионные и релизные инструменты

Python entry point:

- `runtime\python.exe -m app --help`
- `runtime\python.exe -m app scan "input\file.docx"`
- `runtime\python.exe -m app batch "input\file.docx" --mode hard --preset presentation`
- `runtime\python.exe -m app fit-size "input\file.docx" --target-mb 20`
- `runtime\python.exe -m app extract-media "input\file.docx"`

GUI-выбор оптимизации:

- `Готовые размеры`:
  - `1920x1080` - обычный документ;
  - `2560x1440` - презентации;
  - `3840x2160` - печать / архив.
- `Качество JPEG` - общий рычаг сжатия для всех режимов, по умолчанию `82`.
- `Свой размер` - ручная ширина/высота для сильного или нестандартного сжатия.
- `Уложиться в размер` - отдельная автоматическая операция для цели вроде `20 МБ`.

В режиме `Готовые размеры` обработка всегда запускается как `HARD`. В режиме `Свой размер` доступны числовые поля ширины/высоты, выбор `SAFE` / `HARD` и переопределение правила для мелких PNG, по умолчанию `400x400`.

`Уложиться в размер` всегда использует `HARD JPG`: сначала снижает качество до `75`, затем уменьшает разрешение до `1920x1080`, затем качество до `65`, затем лимиты `1600x900` и `1280x720`. Для портретных картинок лимиты автоматически переворачиваются, например `1920x1080` становится `1080x1920`.

Отчёты показывают размер документа, размер встроенных media, decoded-size estimate, summary по форматам, самые тяжёлые image parts и рекомендации по каждому изображению.

GUI-слой ориентирован на понятные автоматические сценарии:

- посмотреть, что внутри DOCX/PPTX;
- оптимизировать Office-файлы через понятный выбор разрешения;
- подогнать файл под целевой размер в МБ;
- нормализовать картинки в sRGB или CMYK;
- извлечь `word/media` и `ppt/media` в `output\<имя-документа>\`.
- выбрать файл или папку `Источник` и папку `Назначение` прямо в Workbench.

## Канонические названия Workbench

Workbench — единый верхний блок маршрутизации, общий для всех NiceGUI-проектов Audion. Он содержит адресные строки `Источник` и `Назначение`, а также кнопки с точными названиями: `Источник`, `Добавить файл...`, `Назначение`, `Сбросить`, `Удалить`, `Список`.

`Источник` может быть отдельным `DOCX`/`PPTX` или папкой. `Назначение` является папкой результатов. Все операции используют выбранные в Workbench пути; отдельные экраны операций не дублируют поля ввода и вывода. После `Сбросить` используются проектные `input` и `output`.

Обычный GUI прячет технические детали форматов. Готовые размеры запускаются как HARD-режим; safe-режим доступен только в ручном режиме `Свой размер`.

Очистка устроена уже, чем обычный I/O: она чистит только управляемые проектные папки `input` и `output`.

Интерактивные CLI/TUI-режимы вроде `SAFE ASK` остаются экспертным путём и не являются основным GUI-сценарием.
